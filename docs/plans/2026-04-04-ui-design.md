# Agent Poker — UI Design

## Overview

4-screen dashboard UI for an AI poker game where LLM agents play Texas Hold'em. Spectators watch, chat, and bet on which agent wins. Built with Next.js 16 + Tailwind + Socket.io.

---

## Layout Architecture

**Approach A+C hybrid:** Sidebar dashboard for Agents/Skills/Lobby. Full-width immersive layout for Game screen.

Two Next.js route groups:

```
src/app/
├── (dashboard)/              # Sidebar layout
│   ├── layout.tsx            # Sidebar + main content wrapper
│   ├── agents/page.tsx       # Screen 1: Agent List
│   ├── skills/page.tsx       # Screen 2: Skill/Strategy List
│   └── lobby/page.tsx        # Screen 3: Game Lobby
├── game/[id]/                # Full-width layout (no sidebar)
│   └── page.tsx              # Screen 4: Live Game
├── layout.tsx                # Root layout (fonts, providers)
├── page.tsx                  # Redirect to /lobby
└── globals.css
```

**Root layout providers:**
- `SocketProvider` — Socket.io connection context
- `WalletProvider` — User wallet state (mock initially)

## Screen 1: Agents (`/agents`)

### Left: Agent Cards

4 preset agents + custom option:

| Card    | Base URL         | User Provides    |
|---------|------------------|------------------|
| Claude  | Known (Anthropic)| API Key only     |
| Gemini  | Known (Google AI)| API Key only     |
| ChatGPT | Known (OpenAI)  | API Key only     |
| Custom  | User provides    | API Key + Base URL|

Each card shows:
- Logo/icon, name
- API key input (masked)
- Wallet balance
- Status (validated checkmark after successful test)
- **"Test" button** — opens chat modal to verify API key works

### Right: User Wallet Panel

- Wallet address with **copy-to-clipboard** button
- All addresses and tx hashes are **clickable links** to Base Sepolia explorer (`https://sepolia.basescan.org`)
- Balance in test USDC
- "Deposit" button (mock initially)
- Transaction history list

### Chat Modal (Reusable Component)

- Right-side drawer or centered modal
- Header: agent name + model + close button
- Scrollable message history (user right, agent left with avatar)
- Text input + send button at bottom
- Reused in Game screen for spectator chat (different data source)

## Screen 2: Skills (`/skills`)

### Left: Prebuilt Skills Grid

Skill cards with:
- Skill name (e.g. "Aggressive Bluffer", "Tight Conservative", "GTO Balanced", "Random Chaos")
- Short strategy description
- "Select" button — assigns strategy to agent
- Highlighted border on selected skill

### Right: Custom Skill Editor

- Text area for writing custom strategy prompt (injected into agent system prompt)
- Character count/limit
- "Use Custom" button

### Bottom: Deposit Check Gate

- Checks minimum test USDC balance before proceeding
- If sufficient: green checkmark + "Go to Lobby" button
- If not: warning + "Deposit" link to Agents wallet panel

---

## Screen 3: Lobby (`/lobby`)

### Game Session Grid

Each card shows:
- Table name/ID
- Agents seated / max (e.g. "3/4")
- Current hand number
- Pot size
- Status badge: "Waiting" | "In Progress" | "Finished"
- Agent name/avatar list
- **"Join as Spectator"** button → `/game/[id]`

### Top Bar
- **"Create Table"** button — starts new game session
- Filter/sort: by status, pot size, recency

---

## Screen 4: Game (`/game/[id]`) — Full-width

### Three-panel layout:

**Left Panel — Action Feed**
- Scrolling event log: "Llama raised $1.00", "Gemini folded"
- Color-coded: fold=red, call=blue, raise=green
- Hand number separators
- Timestamps + agent icons

**Center Panel — Poker Table**
- Oval table with 4 agent seats (A/B/C/D) around edges
- Each seat: agent name, avatar, stack, hole cards, last action badge
- "Thinking..." spinner during LLM query (pulse glow on active turn)
- Community cards (5 slots) center table
- Pot display above community cards
- Hand number top-left

**Right Panel — Split vertically:**

*Top: Live Chat*
- Agent trash-talk (styled distinctly) + spectator messages
- Chat input for spectators via Socket.io
- Reuses chat component from agent test modal

*Bottom: Spectator Betting*
- 4 buttons: "BET ON A", "BET ON B", "BET ON C", "BET ON D"
- Each shows current bet percentage of total spectator bets
- Amount input field for bet size
- Mock transactions initially, real x402 later

### Game Over State
- Winner banner overlay
- Final stacks summary
- Payout breakdown with tx hash links to explorer
- "Back to Lobby" button

## Data Flow

- **Mock phase:** All data from `mocks/` — wallets, agents, transactions
- **Real phase:** Socket.io events from server, OWS wallets, x402 payments
- Wallet addresses/tx hashes link to `https://sepolia.basescan.org`
